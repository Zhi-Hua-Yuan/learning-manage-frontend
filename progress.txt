### Implementation Details

**taskCache.ts:**
- `TASK_LIST_CACHE_TTL_MS = 5 * 60 * 1000` (5 minutes)
- Key: `tick:cache:task-list:v1:{projectId}` for per-project cache
- Key: `tick:cache:task-list:all:v1` for combined all-projects cache
- Exports: `readTaskCache`, `writeTaskCache`, `clearTaskCache`, `readAllProjectsTaskCache`, `writeAllProjectsTaskCache`

**TaskList.vue loadTasks():**
- Overview board (today/week): Uses `readAllProjectsTaskCache()` first, falls back to API fetch, then caches via `writeAllProjectsTaskCache()`
- Single project view: Uses `readTaskCache(projectId)` first, falls back to API fetch, then caches via `writeTaskCache(projectId, records)`
- Switching between today/week views no longer triggers API calls when cache is warm

**Cache invalidation on mutations:**
- `addTask()`: `clearTaskCache(selectedProjectId)` before reload
- `toggleTaskStatus()`: `clearTaskCache(task.projectId)` after API success
- `selectPriority()`: `clearTaskCache(selectedTask.value.projectId)` after API success
- `updateDueDate()`: `clearTaskCache(selectedTask.value.projectId)` before reload
- `selectMilestone()`: `clearTaskCache(selectedTask.value.projectId)` before reload
- `onTextBlur()`: `clearTaskCache(selectedTask.value.projectId)` before reload
- `confirmDeleteTask()`: `clearTaskCache(taskToDelete.projectId)` in onCommitSuccess
- `confirmDeleteMilestone()`: `clearTaskCache(selectedProjectId.value)` in onCommitSuccess
