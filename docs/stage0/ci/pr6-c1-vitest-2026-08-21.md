- 测试使用 jsdom 和本地 axios adapter，不访问真实 API、数据库或外部服务；

- 未新增前端 GitHub Actions，CI workflow 留给后续步骤；
- 未修改业务 API 契约，仅修正空 token 的无效值清理边界。
